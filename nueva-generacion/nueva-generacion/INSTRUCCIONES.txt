CENTRO CULTURAL NUEVA GENERACIÓN — INICIO RÁPIDO

1. Descomprime toda la carpeta.
2. Abre una terminal dentro de esta carpeta (la que contiene index.html).
3. Ejecuta: python -m http.server 8000
4. En el navegador abre: http://localhost:8000

No abras index.html con doble clic: el navegador puede bloquear la carga de datos.
Necesitas conexión a internet para cargar Bootstrap y Chart.js desde CDN.
